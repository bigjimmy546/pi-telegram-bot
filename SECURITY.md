# Security

This bot launches Pi with the service account's normal, unsandboxed filesystem
and shell permissions. Run it only with a private BotFather token and one
explicitly configured Telegram user ID.

Report vulnerabilities through this repository's private GitHub Security
Advisory form. Do not open a public issue containing tokens, credentials,
session files, prompts, local paths, or exploit details.

Only the Pi version named in `SPEC.md` and `docs/ACCEPTANCE.md` is supported.
